When the credits run out, your agent asks you to pay

No dashboard, no card form, no dead run. The API answers 402 with prices and a pay link, the agent passes it on, and it carries on once you've paid.

  1. 01

    The API says why

    An empty key gets a 402, not a vague error. The prices and the next call are in the body, so whoever reads the log knows what to do.

    POST /api/inbox
402 Payment Required
{ "error": "insufficient_quota",
  "pricing": "micro $1 = 10 inboxes, ...",
  "quote_url": ".../api/payments/quote" }
  2. 02

    The agent asks you

    Over MCP, the agent lists the bundles, you pick one, and it hands you a pay link with a QR code for any Bitcoin wallet.

Terminal: tmpmail

An open-source bash CLI built on the same API. It generates inboxes, reads mail in the terminal and copies the activation code to your clipboard. No browser needed.

Get tmpmail on GitHub
