Set A — New concepts (via Impeccable)

A · Capture

Three signals converging to a capture point. Emails arrive, land at one endpoint. Pipeline / collection metaphor.

B · Hourglass

Geometric bowtie. Top filled (email received), bottom empty (expired). Teal neck = the brief moment it exists. Disposable by design.

C · Dashed Ring

Dashed ring = impermanent container. Developer visual language: dashed means draft, optional, temporary. One teal dot — one email, briefly held.
