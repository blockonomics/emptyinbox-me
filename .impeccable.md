## Design Context

### Users
Developers and AI agents who need disposable email addresses for testing, signup flows, and verification. Developers browse in offices (daytime, well-lit). Agents may parse the page programmatically. Both audiences value speed and clarity over decoration.

### Brand Personality
Precise, friendly, dependable — like a well-made developer tool. Utility with warmth. Not cold, not playful.

### Aesthetic Direction
- **Theme**: Light mode (developer context, daytime office use)
- **Primary color**: Emerald green (oklch brand from main.css, h≈162)
- **Typography**: Manrope (headings/labels) + Figtree (body) — geometric, modern, readable without being generic
- **Feel**: Approachable & modern — Stripe/Vercel adjacent without copying them
- **Anti-references**: No glassmorphism, no gradient text, no emoji-heavy UI, no generic card grids

### Design Principles
1. Clarity over decoration — every element earns its place
2. Trust through precision — tight typography, consistent spacing, exact color
3. Developer-first ergonomics — code blocks prominent, tables scannable
4. Brand coherence — emerald accent ties to main site identity
5. Progressive complexity — quick start first, deep reference below
